# Read replit.md First — Every Session

**Rule:** The very first action in every session must be to read `replit.md` in full before doing anything else — before reading any other file, before running any command, before using any tool, and before responding to the user.

**Why:** `replit.md` contains the permanent agent instructions for this project (stack rules, security rules, coding standards, workflow rules, push rules, etc.). Skipping it means working blind and breaking rules you didn't know existed.

**How to apply:** Every session, every import, every new Replit account — no exceptions. Do it first, every time.
